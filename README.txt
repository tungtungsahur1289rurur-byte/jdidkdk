GORIORIO TOP UP — TEMPLATE DEMO

CARA PAKAI
1. Ekstrak ZIP.
2. Buka index.html di browser untuk melihat website.
3. Untuk deploy frontend statis, upload index.html ke Vercel sebagai project static.

PENTING
- Ini prototype frontend/demo. Tidak ada transaksi sungguhan.
- Harga dan katalog di script adalah data contoh; ubah sesuai harga supplier.
- Jangan pernah memasukkan API key Digiflazz atau secret payment gateway ke index.html.
- Integrasi sungguhan membutuhkan backend (misalnya Node.js), database, endpoint supplier, validasi signature, webhook pembayaran, dan pemeriksaan status transaksi.
- Gunakan akun supplier/payment gateway milik sendiri dan ikuti dokumentasi resminya.
